Do NOT create only a Web Service if you expect render.yaml to create PostgreSQL.
The Blueprint contains both the web service and the Postgres database.

SUPPORT BOT (same Render host)
- This project runs the main bot and support bot from the SAME Node/Express service.
- Render Environment must contain SUPPORT_BOT_TOKEN with the support bot token.
- SUPPORT_BOT_USERNAME / SUPPORT_BOT_URL are optional; when omitted, the service calls getMe() and builds the support link automatically.
- SUPPORT_ADMIN_TELEGRAM_IDS should contain the Telegram IDs that receive incoming support requests.
- On startup the service registers https://<your-render-domain>/api/support/webhook for the support bot and keeps the existing main-bot webhook separate.
- The Profile -> Support button loads /api/support/config and opens the support bot discovered from the configured token.

SECURITY
- Keep SUPPORT_BOT_TOKEN only in Render Environment / secret storage; do not commit it to GitHub.



ADMIN / PAYMENTS / MAINTENANCE
- Admin IDs are in ADMIN_TELEGRAM_IDS. The admin panel includes the Тех. работы tab; switching maintenance ON hides the app for non-admin users while admins keep access.
- Admin user cards include a balance adjustment with an optional wager multiplier. For example, +100 Stars with wager x5 adds 500 Stars to the user's outstanding wager requirement.
- Admin promo creation supports both a wager multiplier and a minimum cumulative deposit requirement.
- Stars deposits are counted in total_deposited after Telegram confirms successful_payment; the main bot sends the user a DM with the deposited amount and a 🎮 ИГРАТЬ button.
- GRAM/TON auto-credit requires TON_TOPUP_WALLET_ADDRESS and TON_PER_STAR. TONAPI_KEY is optional but recommended. The app generates a unique memo in the form RING:<UUID> for every top-up intent.
- If a manual transfer does not contain the exact RING:<UUID> memo generated by the app, it cannot be matched automatically to a user.
- Support bot runs in the same Node/Express Render service. Every support operator must open the support bot once and press Start so Telegram allows the bot to send them ticket messages.
