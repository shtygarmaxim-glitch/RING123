# Новые режимы: ДРОП и ПЕНАЛЬТИ

Сделаны по образцу ОТСКОК (соло, вкладки-режимы, ставка, быстрые кнопки, история) и с той же серверной моделью:
клиент шлёт только ставку/режим (+ зону для пенальти), баланс списывается и начисляется на сервере.

## Что добавлено
- server.js: `playPlinko`, `playPenalty`, общий `playSoloRound`; сокеты `plinko_spin` / `penalty_spin` → `*_result`, `solo_modes` (таблицы режимов для клиента).
  Транзакции: `plinko_bet/win`, `penalty_bet/win` (подписи и админ-списки обновлены).
- public/modes.js: экраны обоих режимов (canvas, вкладки, ставки, звук).
- index.html: две карточки в «Играх» + подключение modes.js. styles.css: стили карточек. app.js: кнопки блокируются при техработах.

## Режимы (вкладки)
- ДРОП: 10 рядов, 11 слотов. Лёгкий / Средний / Сложный — разные таблицы множителей (макс. ≈5.3× / 19.7× / 42.5×).
- ПЕНАЛЬТИ: выбираешь зону из 5, защита закрывает 1 / 2 / 3 зоны → шанс гола 80% / 60% / 40%, множитель ×1.15 / ×1.53 / ×2.3.
- Отдача обоих ≈ 92% (используется SOLO_HOUSE_EDGE, по умолчанию 8%).

Таблицы: `PLINKO_SHAPES`, `PENALTY_MODES` в server.js — множители пересчитываются под RTP автоматически.
